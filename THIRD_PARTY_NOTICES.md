## `package:shelf_web_socket` 3.0.0

**Used in:** [`server/lib/src/web_socket_upgrade.dart`](server/lib/src/web_socket_upgrade.dart)

**What was adapted:** the structure of the handler, the WebSocket handshake
header checks (`Connection`, `Upgrade`, `Sec-WebSocket-Version`,
`Sec-WebSocket-Key`), the HTTP status codes those checks return, and the
`Sec-WebSocket-Accept` response.

**Why it was adapted rather than used:** `shelf_web_socket` calls
`WebSocket.fromUpgradedSocket` without passing `maxPayloadLength` and exposes
no way to supply one, so an oversized frame is buffered in full before any
application code can refuse it. The adapted version passes that ceiling
through, which moves the refusal into the frame parser — before a single
payload byte is allocated. Subprotocol negotiation was dropped, as this server
has never offered one.

## Archivo and Bricolage Grotesque

**Used in:** [`client/assets/fonts/`](client/assets/fonts/), declared in
[`client/pubspec.yaml`](client/pubspec.yaml) and named by
[`client/lib/core/app_fonts.dart`](client/lib/core/app_fonts.dart).

**What was copied:** four static TrueType files — Archivo Regular, Medium and
Bold, and Bricolage Grotesque ExtraBold — as served by Google Fonts.

**Why they were bundled rather than fetched:** this app has to open on venue
wifi, and a typeface that arrives over the network arrives after the wordmark
has already been painted in something else.
